# Analysis-of-Thermal-Barrier-Coating-for-Gas-Turbine-Blades
In this topic we discuss with/without coating of blades to protect blades from high temperature
What are Gas Turbine Blades? these types of blades are mainly used in turbines, industries, aircrafts etc.. Every type of blades has there own thermal stability to maintain the blade without any creep or crack. Normal temperature a blade can hold is 750-900 Celcius temperature. If we use an additional coating (Thermal barrier coating) for these blads it will last long and also carries upto 1200 Celcius heat. In this coating we using YSZ material that means yttria stabilized zirconia its a material that reduce the heat at a limit.

# Problem Statement
Gas turbine blades operates under extreme high temperature causing thermal stress, deformation and reduced service life. Applying thermal barrier coating (TBC) can reduce thermal load, but different coating materials behave differently.
This project aims to compare the thermal and structural performance of a gas turbine blade made of Inconel - 713 with and without TBC coatings using FEA.

# Objectives
1. Model a gas turbine blade using CAD.
2. To perform Thermal analysis on :
    1. Bare Inconel - 713 blade.
    2. Inconel - 713 with TBC coatings.
3. To perform Structural (Thermal stress) analysis.
4. To compare :
    1. Temperature distribution.
    2. Deformation.
    3. Mesh analysis.
    4. Von-mises stress.
5. To identify the best coating materials for thermal protection.
